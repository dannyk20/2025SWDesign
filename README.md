# 🎓 Student Management System – Frontend

본 프론트엔드는 학생 정보 및 학사 관리 시스템의 사용자 인터페이스(UI)를 담당하며,

학생 · 교사 · 학부모 · 관리자 간 다양한 권한 구조를 지원하는 React 기반 웹 애플리케이션입니다.

## 기술 스택

- React (with TypeScript)
- Vite
- styled-components
- Zustand
- Playwright(E2E Test), SonarQube(정적 분석)
- Vercel 배포 (자동 http/2 적용)
- Sentry 프론트엔드 에러 모니터링
- Figma 기반 UI 디자인

## UI/UX & 퍼블리싱
- 모바일 반응형 구현
- 발표 시연 기준 모바일 대응 화면 구현 완료
- 사이드바 슬라이드
- 주요 기능 탭 및 목록 구조 모바일 최적화
- 학생/학부모 사용성을 고려한 단순·명확한 UI

## 프론트엔드 주요 기능
### 관리자(Admin)
- 프론트엔드에서 학생·교사·학부모 계정 생성 UI 제공
- 기존 회원가입 기능 삭제 → 관리자가 직접 계정 생성하는 방식으로 변경됨
- 학급별 “담임 배정“ / “학생 배정“ UI 구현

### 학생 상세정보 조회 페이지
- 기본 정보, 성적, 출결, 상담, 피드백을 한 페이지에서 조회
- 레이더 차트를 통한 시각화
- 기간별 필터링 UI 제공

### 학생부(출결) 관리
- 담임교사가 당일 출석 현황을 즉시 확인할 수 있는 화면
- 출결 항목 수정(예: 무단→질병) UI 제공
- 수정 즉시 학생 상세정보 페이지와 반 출석 관리 페이지에 반영됨

### 성적 관리
- 반 전체 성적 조회 UI
- 선택 학생의 성적 수정 기능
- 차트 기반 시각화(레이더 차트)

### 상담 내역 관리
- 상담글 작성 UI (제목/내용/날짜/공개 범위 설정)
- 상담 목록에서 제목·작성자·과목 등 다중 기준 검색 기능 제공

### 피드백 관리
- 성적/행동/출결/태도 항목별 피드백 조회 및 수정 UI

### 보고서 생성
- 프론트엔드에서 성적/상담/피드백 보고서를 PDF/Excel로 생성 가능
- 보고서 생성 및 다운로드 구현

### 학생/학부모 UI
- 편집 불가 형태의 읽기 전용 화면
- 모바일 UI 기반 시연 구성
- 학생 마이페이지에서 “학부모 계정 생성 UI“ 제공
